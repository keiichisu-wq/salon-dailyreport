# 退勤チェック日報（salon-dailyreport）

> この README は `index.html`（main ブランチ）を読んで作成しました。コードから確認できない点は「未確認」と明記しています。

## 目的

サロンのスタッフが退勤時に行うチェック項目（業務・レジ・清掃・閉店作業）を記録し、結果を LINE に貼り付けられるテキストとして出力する日報アプリ。画面タイトルは「退勤チェック日報（End of Shift Checklist）」。

## 主な機能

- **担当者選択**：スタッフ名のボタンから操作者を選ぶ。選択はブラウザの `localStorage`（キー `activeStaff`）に保存され、次回以降も引き継がれる。未選択のままチェックしようとすると警告が出る。
- **チェックリスト（全24項目・4セクション）**：お客様・業務管理／売上・レジ管理／清掃・衛生／閉店・セキュリティ。各項目は2択ボタンで、押した人と時刻（HH:MM）が項目ごとに記録・表示される。
- **条件付き入力**
  - 日付入力：「お客様に送るLINE」は「した」選択時に日付が必須。「カルテの準備」は「完了」選択時に任意で日付入力。
  - テキスト入力：「新規のお客様の予約」で「はい」選択時に、電話担当者名と対応内容（任意）。
  - 色選択（白・青・黒、複数可）：シェーバー掃除、シェーバー充電／電池確認で「した」選択時。必須（未選択だと生成時にエラー）。
- **進捗バー**：記入済み件数 / 全項目数を表示。
- **特記事項メモ**：自由記述欄。
- **LINE用テキスト生成**：未記入・必須入力漏れがあれば警告して中止。問題なければ、日付・参加スタッフ・各項目の結果・要確認項目の一覧・メモを整形したテキストを表示し、クリップボードへ自動コピーを試みる（コピー／全選択ボタンあり）。Ctrl/Cmd+Enter でも生成できる。
- **過去1ヶ月の履歴**（読み取り専用）：今日より前の日報を日付降順で一覧し、展開して詳細を確認できる。Firebase 設定時のみ動作。
- **接続状態バッジ**：ローカルモード／接続中／オンライン／接続エラー。

## 使い方

1. `index.html` をブラウザで開く（スマートフォン向けレイアウト）。ネット接続が必要なのは Firebase を利用する場合のみ（Firebase SDK を CDN から読み込むため）。Firebase 未設定のローカルモードでは、コード上は SDK を参照せずチェック操作と LINE 用テキスト生成が動く構成だが、オフラインでの実機確認は未確認。
2. 画面上部で自分の名前（担当者）を選ぶ。
3. 各項目のボタンを押して記入する。条件付き入力欄が出た項目は必要に応じて入力する。
4. 最後に「特記事項」を書き、画面下部の「LINE用テキストを生成」を押す。
5. 表示されたテキストをコピーして LINE に貼り付ける。
6. 過去の日報を見るときは「📅 過去1ヶ月」タブを開く。

## データの保存方法

- **サーバー側（Firebase Realtime Database）**：`index.html` 内の `FIREBASE_CONFIG` に値を入れると有効になる。保存先は `reports/<YYYY-MM-DD>/` 配下（`selections` / `dateValues` / `textValues` / `colorValues` / `memo`）。変更は他の端末にもリアルタイムで反映される（同じ日付キーを購読）。入力欄の保存は 0.8 秒、メモは 2 秒のデバウンス後。
- **ブラウザ側**：`localStorage` に保存するのは選択中の担当者名のみ。
- **ローカルモード**：リポジトリ上の `FIREBASE_CONFIG` は全項目が空文字のため、このままでは Firebase に接続せず、チェック内容・メモは画面のメモリ上にのみ保持される（再読み込みで消える）。履歴タブも「Firebaseが設定されていない」旨の表示になる。

## 設定する場所

`index.html` の `<script>` 冒頭「設定エリア」：

- `STAFF_NAMES`：スタッフ名の一覧
- `FIREBASE_CONFIG`：Firebase の接続情報（コード内コメントに設定手順あり）
- `SECTIONS`：チェック項目の定義
